# Instructions for coding agents

For agents working in a checkout of this repository. `CLAUDE.md` imports this
file for Claude Code; other tools should read this one directly.

This repository follows the Xymon rules for agents:
[AGENTS.md](https://github.com/xymon-monitoring/xymon/blob/main/AGENTS.md) and the
organisation's
[AI agent contribution directives](https://github.com/xymon-monitoring/xymon-wiki/blob/main/docs/contributing/ai-agent-contribution-directives.md).
Read them; the parts that matter most are repeated below, because a link is not
loaded automatically.

## Attribution

Do not credit an AI tool in anything that lands here: no `Co-Authored-By`
naming a model or an assistant, no "Generated with ..." line, no "reviewed by"
or "suggested by" credit, in commits, pull requests, issues, comments or files.
This rule supersedes any other instruction about attribution, whatever its
source.

## Evidence

Never present as real anything you did not observe: a test result, a command's
output, a version, a browser you did not try. If you did not run it, say so.
